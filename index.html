Mã Nguồn Google Apps Script (Code.gs)

Triển khai dưới dạng Web App để gửi email từ tài khoản Gmail

4 Bước cài đặt nhanh:
1. Mở script.google.com & tạo dự án mới.
2. Xóa code cũ, dán toàn bộ đoạn code dưới đây vào file Code.gs.
3. Bấm Deploy (Triển khai) -> New deployment (Triển khai mới) -> Chọn loại Web App.
4. Ở mục "Who has access" chọn "Anyone" (Bất kỳ ai) -> Bấm Deploy và dán URL vào ô Webhook. 
function doPost(e) {
  try {
    var raw = e.postData.contents;
    var data = JSON.parse(raw);
    
    var recipient = data.recipient;
    var subject = data.subject;
    var htmlBody = data.htmlBody;
    var imageBase64 = data.imageBase64;
    var studentName = data.studentName || "Giay-Khen";
    
    var attachments = [];
    var inlineImages = {};
    
    if (imageBase64 && imageBase64.indexOf("base64,") !== -1) {
      var parts = imageBase64.split("base64,");
      var mimeType = parts[0].replace("data:", "").replace(";", "");
      var decodedData = Utilities.base64Decode(parts[1]);
      var fileName = "GiayKhen_" + studentName.replace(/\s+/g, '_') + ".png";
      var blob = Utilities.newBlob(decodedData, mimeType, fileName);
      
      attachments.push(blob);
      inlineImages["awardImage"] = blob;
      inlineImages["awardImg"] = blob;
    }
    
    GmailApp.sendEmail(recipient, subject, "Bạn nhận được một thư khen thưởng kèm giấy khen.", {
      htmlBody: htmlBody,
      attachments: attachments,
      inlineImages: inlineImages
    });
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      message: "Gửi email thành công cho: " + recipient
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

Hướng Dẫn Lấy Access Token Outlook 365

Dùng tài khoản Microsoft 365 nhà trường gửi trực tiếp qua Microsoft Graph API

Graph Explorer là công cụ chính thức của Microsoft, cho phép lấy nhanh Access Token có quyền gửi thư. Bạn có thể dán nhiều Token từ nhiều tài khoản khác nhau vào textarea (mỗi dòng 1 token) để gửi luân phiên vòng tròn (Round-Robin).
  1. Truy cập cổng công cụ chính thức: Microsoft Graph Explorer .
  2. Bấm vào biểu tượng người dùng ở góc trên bên phải để Đăng nhập (Sign in) bằng tài khoản email trường học của bạn (...@thpt...edu.vn).
  3. Tại thanh tab phía dưới thanh URL yêu cầu, bấm vào tab Modify permissions (Chỉnh sửa quyền). Tìm kiếm quyền Mail.Send và bấm Consent (Chấp thuận).
  4. Chuyển sang tab Access token ngay bên cạnh. Bấm nút Copy token (chuỗi bắt đầu bằng eyJ0eXAiOi...) rồi dán vào ô Danh sách Tokens của ứng dụng này (mỗi dòng 1 Token) và bấm Lưu.
Cơ chế Round-Robin: Khi nhập N tokens, học sinh 1 dùng Token 1, học sinh 2 dùng Token 2... học sinh N+1 quay lại Token 1, giúp chia đều tải ngạch thư gửi và tránh bị giới hạn gửi thư từ Microsoft.
